Why Developers Choose CHEST

Modern architecture engineered for speed, reliability, and modularity.

⚡

High-Speed Concurrency

Parallel directory traversal powered by fastwalk and microsecond scoring with fzf/src/algo. Processes 100k+ files across multiple CPU cores.

🛡️

100% Reversible & Safe

Dry-run mode, collision detection (skip, rename, replace, abort), and instantaneous rollbacks via chest undo.

👁️

Real-Time Watch Mode

Continuous filesystem event watching with chest watch. Automatically detects new downloads or dropped assets and sorts them immediately.

🧠

Local SQLite Intelligence

Stores metadata, storage statistics, and cryptographic SHA256 hashes inside pure-Go SQLite. Detect byte-identical duplicates with zero cloud exposure.

🔌

Process-Isolated Plugins

Extend CHEST with custom classifiers and rules using HashiCorp's go-plugin over RPC. Your plugins run in independent processes.

🎯

Expressive Rule Engine

Combine type, size, extension, regex, MIME type, and dates with boolean expressions like type=image && size>5MB -> RAW/.
