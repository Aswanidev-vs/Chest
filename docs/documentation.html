CHEST Documentation

CHEST is designed as a standalone, offline-first, highly concurrent file organization and storage intelligence tool written in Go.

Installation Methods

1. Go Install

If you have Go installed, compile directly into your Go bin directory:

go install github.com/Aswanidev-vs/chest/cmd/chest@latest

2. Curl One-Liner (macOS & Linux)

Automated installer script:

curl -sSL https://raw.githubusercontent.com/Aswanidev-vs/chest/main/install.sh | bash

3. Windows PowerShell

Run within PowerShell terminal:

irm https://raw.githubusercontent.com/Aswanidev-vs/chest/main/install.ps1 | iex

Quick Start

Sort files in your current folder using the default rules:

chest sort

Safe preview with dry run:

chest sort ~/Downloads --dry-run

Revert what was just sorted:

chest undo

Core CLI Commands

chest sort [target] [flags]

Organizes files based on rules or presets.

  • -t, --type: Group by file category (Images, Videos, Documents, etc.)
  • -s, --size: Group by size thresholds
  • -f, --format: Group by file extension
  • -p, --preset <name>: Use a built-in preset (downloads, media, developer, documents, photos)
  • --rule "expression -> Destination": Specify on-the-fly custom rules
  • -i, --into <folder>: Custom root destination directory
  • -n, --dry-run: Simulate changes without moving files
  • -y, --yes: Skip interactive confirmation prompt

chest search [pattern] [path] [flags]

Blazing fast search using fastwalk parallel multi-core traversal and fzf/src/algo scoring.

  • -c, --content <query>: Grep inside file contents (shows line number and match snippet)
  • -t, --type <category>: Filter by category (e.g. image, code)
  • -e, --ext <exts>: Comma-separated extension filter (e.g. go,md,png)
  • -s, --size <cond>: Size condition (e.g. >1GB, <50MB)
  • -m, --modified <cond>: Time condition (e.g. >30d)
  • -r, --regex: Regex pattern matching
  • -j, --json: Output results as JSON for shell scripting

chest watch [directory] [flags]

Continuous automated watcher powered by fsnotify. When files finish downloading or are saved, CHEST immediately sorts them into compartments.

chest watch ~/Downloads --preset media --debounce 500ms

chest index & chest clean

CHEST indexer persists file metadata and optional SHA256 hashes into local SQLite (~/.chest/index.db).

  • chest index [path] --hash: Compute incremental SHA256 hashes
  • chest index --clear: Empty the indexed files table without deleting undo history
  • chest clean: Empties index cache
  • chest clean --all: Deletes the entire SQLite database file

File Intelligence: stats, duplicates, analyze

  • chest stats: Instant storage and category distribution breakdown
  • chest duplicates [path]: Byte-for-byte duplicate finder using cryptographic hashes
  • chest analyze [path]: Health report identifying stale files (>180 days), zero-byte files, and largest consumers

chest man [command]

Displays a detailed manual page with full description, flags, and usage examples — works like the Linux man command but built into the CLI.

chest man sort chest man search chest man watch

chest preset

Lists all available built-in sorting presets (downloads, media, developer, documents, photos) with their target file types.

chest preset

chest version

Prints CHEST version, OS/architecture, and Git commit SHA (when built from a Git checkout).

chest version

🔌 Plugin Architecture & Guide

Why external plugins? CHEST uses hashicorp/go-plugin over RPC. Plugins run in separate processes. If a plugin crashes or has bugs, CHEST's planning and filesystem safety mechanisms remain 100% protected.

How Plugins Work

A CHEST plugin is simply an executable binary paired with a manifest.json placed in ~/.chest/plugins/<plugin-name>/.

Plugins can expose custom classifiers, custom rules, or new file presets.

Building a Plugin: Step-by-Step Tutorial

Step 1: Create your plugin project directory

mkdir chest-anime-plugin cd chest-anime-plugin go mod init chest-anime-plugin

Step 2: Write your plugin binary (main.go)

package main import ( "strings" hplugin "github.com/hashicorp/go-plugin" "github.com/Aswanidev-vs/chest/internal/plugin" "github.com/Aswanidev-vs/chest/internal/models" ) type AnimePlugin struct{} func (a *AnimePlugin) GetInfo() (plugin.Manifest, error) { return plugin.Manifest{ Name: "anime", Version: "1.0.0", Description: "Classifies anime and manga media", Capabilities: []string{"classifier"}, Binary: "anime-plugin", }, nil } func (a *AnimePlugin) Classify(filename string, ext string) (string, error) { lower := strings.ToLower(filename) if strings.Contains(lower, "[subs]") || strings.Contains(lower, "1080p") { return "Anime", nil } if ext == "cbr" || ext == "cbz" { return "Manga", nil } return "Other", nil } func (a *AnimePlugin) GetCustomRules() ([]models.Rule, error) { return nil, nil } func main() { hplugin.Serve(&hplugin.ServeConfig{ HandshakeConfig: plugin.HandshakeConfig, Plugins: map[string]hplugin.Plugin{ "classifier": &plugin.ClassifierPluginRPC{Impl: &AnimePlugin{}}, }, }) }

Step 3: Create manifest.json

{ "name": "anime", "version": "1.0.0", "description": "Classifies anime and manga media", "author": "YourName", "capabilities": ["classifier"], "binary": "anime-plugin" }

Step 4: Build and Install

go build -o anime-plugin . # Install into CHEST chest plugin install .

Step 5: Verify

chest plugin list chest plugin info anime

Managing Plugins via CLI

  • chest plugin list: Show all installed plugins
  • chest plugin info <name>: View detailed capabilities and author info
  • chest plugin install <directory>: Installs a local plugin folder
  • chest plugin remove <name>: Completely uninstalls the plugin
